# 0.9.1
GUI Windows/Tk не запускался. Кеши ускоряют PIL/ядро, но не доказывают FPS на ноутбуке. Память исходных карт остаётся большой. Для масштабированного фона>48MiB используется более медленный fallback. Формы переразложены, фактическую доступность кнопок при DPI пользователя нужно проверить. Окна, не связанные с событием, ещё могут требовать доработки. Геометрия сталкивающихся тел упрощённая. Время кадра в статусе не включает полную стоимость вывода на экран. Новый запуск по умолчанию использует .venv старой0.9.0; не удалять её или создать свой через install.bat.

# Ограничения 0.9.0
НЕТ запуска Tk/Windows GUI в среде сборки. Тесты ядра не доказывают исправность UI.
Требуется ручная проверка окон/масштаба/DPI на ноутбуке. Нет гарантии отсутствия багов.
31 автоматический тест пройден, реальный системный FFmpeg encode/decode пройден.
Кодер из установленного на Windows imageio-ffmpeg отдельно не запускался.
NPC не ищут обходные пути; заблокированный шаг пропускается. Карты вне сцены
не обновляются. В диалогах замораживаются все NPC, не только собеседник.
Список событий только текущая карта, номера меняются после удаления/перестановок.
Подписи событий пока всегда в редакторе, отдельного скрытия подписей нет.
Рамка вокруг клетки, а не спрайта. Collider упрощённый, масштаб графики его не меняет.
Размер/опора общие для ресурса, per-instance scale пока нет.
Дверь переходит по кнопке, не по касанию автоматически. Шаблоны доступны с панели.
Ресурсы проектов ссылками; перенос одного JSON не переносит свои PNG/фон/шрифт.
Встроенная демографика пересоздана из-за отсутствия PNG во входном TXT; можно
вернуть baseline PNG из0.8.0 через COPY_OLD_ASSETS.bat, не затрагивая проекты.
Нет Undo, drag/drop между ветками, удаления профиля с проверкой использования,
загрузки JSON дубля, звука, погоды, вставок GIF/видео, savegame.
Старая миграция v1–3 без старых цветовых кистей, не полная визуальная идентичность.
Очень большие карты/много PNG целиком в RAM. NPC bodies lookup квадратичный,
сотни подвижных NPC требуют оптимизации и профилирования.
Отмена экспорта между кадрами; зависший pipe может задержать отмену.
Журналы без ротации, после аварий возможны оставшиеся partial MP4.
