# RPG Constructor 0.8.0 — страницы событий и Если / Иначе
Полная сборка, не патч. Распаковать в НОВУЮ папку. Python3.12/Windows с tkinter.
install.bat (интернет для зависимостей), затем run_editor.bat. Старую папку
0.7.x не удалять: новая схема v6, старые редакторы её не читают.

## Главное изменение
У события теперь несколько страниц. В каждой своё условие, изображение/кадр,
способ запуска и список команд. Используется ПОСЛЕДНЯЯ подходящая страница.
Страница 1 без условий — обычное исходное состояние; страница 2 с условием
показывает изменённый объект. Это упрощённая собственная система, не клон MZ.
Переключатель — состояние ВКЛ/ВЫКЛ, а не картинка. Общий может связать рычаг
и дверь. Локальные A–D принадлежат одному событию (например, уже поговорили).

## Первый тест
Демо открывается сразу. Просмотр; WASD/ЦФЫВ/стрелки ходят, Пробел/Enter —
взаимодействие. NPC в (4,4), рычаг (7,4), дверь (10,4), кухня и выход назад.
Поговорите с NPC дважды: вторая беседа — другая страница по локальному A.
Рычаг переключает две страницы и открывает дверь. На кухне кнопка (9,5)
имеет свой локальный A, не связанный с NPC. Escape — редактор.
Сцена → Сбросить исполнение обнуляет общие и локальные состояния.

## Открыть/удалить событие
Инструмент Событие / выбор: ОДИН щелчок выбирает, ДВОЙНОЙ открывает редактор
(на пустой клетке — новое событие). Delete или Удалить событие — удаление с
подтверждением. Кнопка Удалить событие остаётся также внизу окна события.
Нажмите Сохранить после изменений. Стереть убирает только препятствия.

## Редактор страниц
Вверху список страниц, + Страница, Копировать страницу, Удалить страницу.
Слева имя страницы, условия, запуск, Изображение / выбрать кадр.
Общий переключатель + ВКЛ/ВЫКЛ; локальный A–D + ВКЛ/ВЫКЛ. Если заданы оба,
должны выполниться оба. Пустые условия — страница подходит всегда.
Копирование сохраняет графику и команды, затем меняйте условия/кадр.
В окне изображения слева ресурсы, справа PNG с сеткой, щёлкните кадр → Выбрать.
Кадры в UI описываются с 1, в JSON с 0. Для персонажа строка = направление.
Один PNG рычага содержит два состояния рядом, никаких отдельных off/on-файлов.

## Команды и Если / Иначе
Добавить → выбрать команду. Двойной щелчок редактирует.
Типы: текст, общий переключатель, локальный переключатель, переход, Если/Иначе.
Выберите Если, задайте условие → ОК. В дереве появятся папки То и Иначе.
Выберите То → Добавить: команда попадёт в истинную ветку.
Выберите Иначе → Добавить: команда попадёт в ложную ветку.
Чтобы добавить после условия, выберите строку самого Если и нажмите Добавить.
Если ничего не выбрано, команда добавляется в конец корневого списка.
Удаление строки Если удаляет весь блок с обеими ветками. Undo пока нет.
Выше/Ниже переставляют в пределах одной ветки; между ветками перенос пока
через повторное создание, drag-and-drop нет. Поддерживается вложенность до 20.

## Создать простой рычаг (быстрый путь)
Выбрать инструмент Простой рычаг → клетка → название → лист рычага → Выбрать.
Мастер создаёт ОБЫЧНОЕ событие с двумя страницами:
1: без условий, кадр 1, команда включить общий переключатель;
2: условие этот переключатель ВКЛ, кадр 2, команда выключить.
Откройте двойным щелчком и посмотрите — нет скрытой отдельной логики.
Это меняет рычаг, не включает дверь автоматически.

## Дверь по рычагу
Создайте общий переключатель или используйте созданный рычагом.
Событие двери → страница 1 без условий и без графики → Добавить Если/Иначе.
Условие: нужный общий переключатель ВКЛ.
То: Перейти на локацию, карта/клетка появления.
Иначе: Показать текст «Заперто».
Сохранить событие → Сохранить проект. Можете подсмотреть готовую дверь демо.

## Своя графика
Герой… → Добавить свою графику… → файл. Три режима:
- Статичный персонаж: один рисунок, без ходьбы, копируется на четыре направления.
- Персонаж: лист из четырёх строк ↓ ← → ↑, указать размеры/количество через запятую.
- Объект: один ряд кадров. Например лист 192×112, кадр96×112, количество2.
Опора X/Y — точка ног внутри кадра, по умолчанию центр/низ.
Новый импорт копируется в assets/imported. Затем выберите ресурс и кадр.
Количество кадров не ограничено восемью в коде, но ресурсы компьютера конечны.
Размеры кадров независимы от сетки карты. UI импорта PNG-последовательности нет.
Полного удаления ресурсов с проверкой использования пока нет.

## Настройки, запись, ресурсы
Настройки: камера, скорость, FPS анимации, TTF/OTF/размер текста, качество
preview native/economy/1080p, размер MP4. Разрешение видео чётное 16:9 до4K.
Шрифты копируются в assets/imported; право передачи шрифта проверяйте сами.
Перенос по словам и автопагинация, ручной Enter сохраняется. Имя одной строкой.
Записать → разыграть → Стоп → MP4. Снимки включают локальные/общие состояния,
диалоги и карты. Страницы/внешний вид выбираются так же в preview и видео.
MP4 30fps H264 с потерями, без звука. Кодирование отдельно от исполнения.
После Стоп оформление заморожено, разрешение можно менять. JSON дубля только
диагностика, загрузки после перезапуска нет. До выхода экспортировать!
Фоны/профили/шрифты в JSON ссылками. Пока НЕ самодостаточный пакет проекта:
для переноса нужна папка ресурсов и исходные фоны. Файлы не удалять отдельно.
Recovery при обычном выходе projects/recovery.json (открыть вручную).
Коллизии необязательные, по умолчанию выключены; NPC не блокируют автоматически.
Погоды, видео/GIF вставок, движения NPC и сохранения игры пока нет.

## Старые проекты
Открыть исходный JSON из старой папки, не переносить один JSON без ресурсов.
Карты v1–3 / проекты v4–5 преобразуются в v6. Старые условные команды станут
блоками Если. Старый visual_flag создаст две страницы. Старые off/on картинки
автоматически соберутся в новый PNG в assets/imported новой сборки.
Пользовательские профили ищутся в assets/profiles.json рядом со старой папкой.
Если старые ресурсы не найдены, будет ошибка — не заменяйте их случайными.
Сохранить как в НОВЫЙ файл. Держать старую папку до проверки всего проекта.
