## Безопасное открытие старого проекта
Файл → Открыть → JSON в исходной папке старого проекта. Пути к своим ресурсам
остаются ссылками на оригиналы. Не удалять и не перемещать старую папку.
Схема v6 преобразуется в v7. При первом сохранении старого формата автоматически
предлагается не диалогом, а назначается НОВОЕ имя *_090_дата.json рядом с исходным.
Имя видно в статусе/журнале. Сохранить как позволяет выбрать другое место.
Старый редактор не читает v7. Не открывать сохранённый v7 в старом редакторе.
Ручной выбор старого имени через Сохранить как может его перезаписать — избегать.
Для проектов v1–5 сохранена прежняя миграция с её ограничениями (см. справку080).

## Ресурсы демонстрации
В присланном TXT нет PNG и TTF. Для полной запускаемой сборки технические
спрайты и фоны демо пересозданы в тех же размерах, но не пиксель-в-пиксель.
Ваши пользовательские ресурсы не заменяются. Чтобы вернуть именно прежний вид
встроенного демо: после install.bat, ДО запуска редактора, необязательно запустить
COPY_OLD_ASSETS.bat и указать папку старой0.8.0. Копируются только9 известных PNG
с совпадающими размерами; JSON, свои ресурсы, двери и учебная карта не трогаются.
Старые файлы только читаются. Это необязательный шаг, новая сборка автономна.

## События на карте и поиск
Слева список событий ТЕКУЩЕЙ карты с картинкой, именем и координатами.
Поиск по имени, номеру в списке и внутреннему ID. Щёлкнуть строку — найти на
карте/выделить. Двойной щелчок или Открыть выбранное — редактировать.
Номера в списке порядковые, не постоянные идентификаторы.
На карте толстые жёлтые рамки с тёмной обводкой/подписями; выбранное — голубое.
Один щелчок на карте выбирает, двойной открывает/создаёт. Delete удаляет.
Техническая рамка обозначает клетку события, не размер картинки и не коллайдер.

## Панель события
Вверху список страниц, + Страница, Копия, Удалить страницу.
Слева две вкладки: Страница и Изображение. Справа дерево команд.
Последняя страница с подходящими условиями имеет приоритет.
Первая без условий — исходное состояние. Локальные A–D относятся только к
этому событию; общие переключатели связывают разные объекты и карты.
На вкладке Изображение миниатюра, размер кадра, масштаб; выбор кадра из PNG.
Размер и точка опоры относятся КО ВСЕМ событиям с этим ресурсом, не только
к текущей странице. Масштаб0.1–8, опору можно указать числами или щелчком.
На просмотре опоры рисунок вписан в окно, а фактический размер дан подписью.
Сетка карты независима от размеров графики. Количество кадров не фиксировано.
Размер героя — отдельная кнопка сверху. Она также меняет ресурс, не карту.
Столкновения пока упрощённые, ширина спрайта не задаёт физическую ширину.

## Движение NPC
Событие → вкладка Страница → Движение NPC.
Режимы: стоять / бродить рядом / подходить к герою / по маршруту.
Скорость в px/с, пауза между шагами, радиус блуждания в клетках.
Маршрут: шаг вверх/вниз/влево/вправо, ждать, повернуться; повтор включается.
Порядок меняется Выше/Ниже. Каждый шаг = одна клетка.
Если упёрся в препятствие, шаг пропускается; поиск обходного пути НЕ реализован.
Во время диалогов ВСЕ NPC текущей сцены приостанавливаются, собеседник
поворачивается к герою. NPC учитывают преграды и твёрдые события/героя.
Движение начинает работать в Просмотре, не в режиме расстановки объектов.
После правок движения лучше Сцена → Сбросить исполнение: NPC вернутся на места.
Встроенный Сосед ходит вправо/влево с паузами. Старые NPC по умолчанию неподвижны.
Снимки записи сохраняют позиции/направления/анимацию NPC, MP4 их воспроизводит.
Вне текущей карты NPC не симулируются, позиция сохраняется в текущем сеансе.

## Проходимость
Старая кисть Преграда закрывает целую клетку. Стереть снимает только эту разметку.
Новый инструмент Проходимость: выбрать направление и один из двух режимов.
1. Стена в обе стороны — запрет через выбранный край туда и обратно.
2. Запрет выхода в одну сторону — нельзя ВЫЙТИ из выбранной клетки в указанном
направлении, но можно зайти через этот край обратно.
ЛКМ ставит, ПКМ удаляет запрет выбранного типа/направления. Для двухсторонней
стены удалять в режиме стены, чтобы снять парную запись соседней клетки.
Красная линия с поперечиной указывает запрещённое направление выхода.
Разметка отображается при Вид → Разметка. Вне карты проход запрещён всегда.
Для героя включить Сцена → Проверять препятствия! По умолчанию выключено.
NPC учитывают разметку независимо от этого переключателя, чтобы не ходить
через стены при постановке сцены. Событие преграждает путь — отдельная настройка
страницы. При выключенных столкновениях герой может проходить и сквозь него.
Полигональных/настраиваемых прямоугольных коллайдеров в этой версии нет.

## Двери
Верхняя панель → Дверь… → щёлкнуть пустую клетку. Три шаблона:
- обычный переход;
- дверь по общему переключателю (закрытая/открытая страницы);
- открыть без перехода (локальный A, открытие/закрытие по взаимодействию).
Выбрать общий переключатель от рычага, карту, клетку появления, текст «Заперто».
Если нет переключателя — заранее Сцена → Общие переключатели, либо поставить
Простой рычаг: он сам создаёт переключатель с введённым названием.
Мастер добавляет стандартные страницы, их можно редактировать. Кадры закрыто/
открыто — один PNG door_wood.png. Переход запускается взаимодействием,
не автоматическим наступанием (можно изменить запуск страницы вручную).
При включённых коллизиях закрытая страница препятствует проходу, открытая — нет.

## Потренироваться самостоятельно
Выбрать карту training в списке карт. Там нет готовых событий.
1. Инструмент Простой рычаг → клетка → название «Учебная дверь» → графика рычага.
2. Инструмент Дверь… → другая клетка → Дверь по переключателю.
3. Выбрать созданный общий переключатель; куда ведёт room, клетка2,4.
4. Просмотр → подойти к двери: заперто. Включить рычаг, снова дверь: переход.
5. Стоп/редактор → выбрать training; Сбросить исполнение возвращает на стартовую
карту room, поэтому после сброса выбрать training снова.
Клетки и большие проёмы учебной карты — только ориентиры, невидимых переходов нет.

## Команды
У строк увеличена высота, чередуется фон, ветки выделены цветом.
Добавлены Комментарий и Разделитель: ничего не выполняют.
Если/Иначе: выбрать строку То или Иначе и Добавить — вставка внутрь ветки.
Выбрать команду и Добавить — вставка после неё. Пустой выбор — конец корня.
Выше/Ниже в одной ветке. Undo/перетаскивания между ветками пока нет.
Длинные текстовые команды отображаются сокращённо, полный текст — двойной щелчок.

## Запись/экспорт/диагностика
WASD/ЦФЫВ/стрелки — движение, Пробел/Enter — взаимодействие, Escape — редактор.
Записать → разыграть → Стоп → MP4. Настройки: шрифт, масштаб камеры,
preview native/economy/1080p, размер видео. MP4:16:9,30fps,H264,без звука.
Во время записи не открывать редакторы. После остановки исполнение заморожено
в дубле; настройка разрешения экспорта остаётся доступна.
JSON дубля диагностический, UI его загрузки пока нет. Экспортировать до выхода.
Журналы: logs, Вид → Журнал. Кодер: *.ffmpeg.log рядом с видео.
check.bat —31 тест. Подробный статус в TEST_STATUS_RU.md.
Windows/Tk GUI здесь не запускался: проверить расположение кнопок на ноутбуке.
