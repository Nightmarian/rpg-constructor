#0.9.4 — компактная панель, темы, случайное движение
Пакет для установленной0.9.3. Исходная папка не изменяется.

## Установка
Закройте редактор. Распакуйте архив отдельно, запустите UPDATE_0.9.4.bat,
выберите установленную папку0.9.3 (main.py, editor, engine, assets).
Рядом создаётся новая папка_0.9.4. Запускать run_editor.bat оттуда.
Старые папки не удалять: используются прежнее Python-окружение и ссылки ресурсов.
Виртуальное окружение/logs/recordings не копируются; launcher0.9.3 сохраняется.
Установщик сначала проверяет, что знает структуру нужных функций, и готовит
изменения в памяти. Только затем копирует в новую папку. Не применять payload
вручную: NPC/app/modal меняются установщиком адресно, а не заменяются0.9.0.

## Левая панель события
Сохранены две колонки0.9.0 и один ряд кнопок команд. Нет нового разделителя,
нет новой прокручиваемой оболочки. Нижние действия всего окна и действий
каждой левой вкладки получают место ПЕРЕД растягиваемым содержимым.
Длинные пояснения убраны, вертикальные отступы уменьшены. Выбор общего
переключателя сужен до20символов (полное имя остаётся в списке).
Миниатюра180×120 вместо280×210: размер спрайта НА КАРТЕ не меняется.
Кнопки Движение NPC/Переключатели и выбора графики сохранены.
При предельно маленьком окне содержимое всё ещё ограничено физическим размером
экрана. Минимальные размеры не означают поддержку любого DPI. Нужен прогон Windows.
Окно движения заново разложено в обычную grid-сетку: растягивается только список,
форма/добавление/Применить/Отмена остаются отдельными строками. Остальные формы
редактора этим обновлением не переписываются.

## Тема
Вид → Тема → Светлая/Тёмная. Выбор сохраняется в editor_settings.json рядом
с программой, НЕ в проекте. По умолчанию светлая. Тёмная использует ttk clam.
Оформляются свои окна, поля, вкладки, списки, команды, текст/журнал и скроллы.
Системные меню/заголовки Windows и нативный выбор файла могут остаться светлыми.
Фон/ресурсы карты, игровой текст/шрифты и MP4 не перекрашиваются.
Тема отдельным модулем, обход виджетов только при открытии окна/смене темы,
не в цикле каждого кадра. Кеши рендера не менялись.

## Случайное движение
Событие → Движение NPC → Случайное блуждание. Это существовавший режим random,
только название сделано явным. Радиус ограничивает блуждание вокруг исходной клетки.
По маршруту → список команд теперь содержит:
- Случайный шаг — одна из четырёх сторон, без поиска обходного пути;
- Случайная пауза — задать минимум и максимум секунд (например1–3).
Случайный шаг В МАРШРУТЕ не ограничен радиусом блуждания: действует карта,
границы и столкновения. Обычное блуждание — отдельный режим с радиусом.
Генератор по умолчанию не запускается с постоянным4129. Для повторяемых тестов
можно вручную задать random_seed:42 в JSON проекта; UI для seed пока нет.
Запись сохраняет реальные положения NPC: при экспорте случайность не разыгрывается
заново. Сам код экспорта/снимков в этой версии не меняется.

## Совместимость
Формат остаётся7. После использования новых random_step/random_wait старые
редакторы0.9.3 и ниже не знают этих команд и могут отказать в открытии.
Сохраните такой проект под НОВЫМ именем через Сохранить как, храните старую копию.
Существующие маршруты/страницы сохраняются. Настройки темы отдельно от проекта.
