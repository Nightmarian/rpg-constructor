# 0.9.1 — исправление интерфейса, ускорение и затемнение
Обновление именно присланной версии0.9.0. Формат проекта7 сохранён.

## Установка без изменения старой папки
1. Закрыть редактор0.9.0.
2. Распаковать пакет обновления в отдельную папку и запустить UPDATE_0.9.1.bat.
3. Выбрать УСТАНОВЛЕННУЮ папку0.9.0, где main.py, editor, engine и assets.
4. Программа создаст рядом НОВУЮ папку с суффиксом _0.9.1; если имя занято,
добавит дату. Исходная0.9.0 остаётся без изменений.
5. В новой папке запустить run_editor.bat. Пакет/старую папку пока не удалять.
Готовая папка содержит настоящие ресурсы/проекты из вашей0.9.0, без перерисовки.
Старые recordings/logs и виртуальное окружение не копируются.
Сразу используется Python из старого .venv, если он существует. Для независимого
окружения можно выполнить install.bat в НОВОЙ папке (нужен интернет).
Фоны/шрифты/свои спрайты, на которые проекты ссылаются абсолютными путями,
могут по-прежнему находиться в старой папке. Не удаляйте её.
Перед копированием сверяются изменяемые исходники с присланным sources_090.txt.
Если код другой, установщик откажется: пришлите актуальные исходники, не обходите
проверку. Пакет не самостоятельная программа без установленной0.9.0.

## Окна событий
Кнопки сохранения/отмены закреплены снизу ДО размещения растягиваемой области.
Кнопки страниц вынесены на отдельную строку. Вкладки Страница/Изображение
получили вертикальную и горизонтальную прокрутку. Команды — кнопки3+2,
а не длинный ряд; список команд с вертикальным скроллом.
Формы команды, движения и опоры тоже прокручиваются, нижние действия закреплены.
Стартовый размер учитывает разрешение экрана. Масштабирование PNG не нужно
для доступа к кнопкам; при большом DPI содержимое можно прокрутить полосой.
Раскладка на Windows ещё нуждается в ручной проверке, см.TEST_STATUS_RU.md.

## Производительность
NPC: кеш активных страниц, один обход на состояние вместо повторных обходов
при каждом запросе позиции/тел; запись сохраняет только нужные поля актёров.
Предпросмотр не копирует каждый кадр всю структуру флагов/диалогов.
RenderCache: ограниченные по памяти кеши масштабированного фона и спрайтов.
При размере масштабированного фона до48MiB камера берёт готовый фрагмент,
а не выполняет bilinear-transform целого окна заново. Для огромных карт остаётся
прежний безопасный путь с кешем отдельных видов. Кеши максимум примерно
48+48+24MiB плюс исходные изображения и текущие буферы.
Камера и актёры выровнены до пикселя выходного кадра, чтобы фон не дрожал
относительно персонажей. Разрешение/качество автоматически не понижаются.
В строке статуса время обработки кадра; это НЕ полный FPS Windows/Tk/экрана.
Если всё ещё медленно — сравнить покой/ходьбу героя и прислать мс/размер кадра.

## Разметка
Вид → Разметка включено:
- красная заливка и белое ×: вся клетка непроходима;
- толстая красная линия: стена в обе стороны;
- жёлтая граница + зелёная стрелка: можно только по зелёной стрелке;
- оранжевая заливка/метка: активная страница события преграждает путь.
Направление в инструменте Проходимость по-прежнему означает запрещённый ВЫХОД.
Зелёная стрелка указывает противоположное, разрешённое направление перехода.
У героя для столкновений нужна опция Сцена → Проверять препятствия.
NPC всегда учитывают разметку. Пустая клетка без отметок не гарантирует отсутствие
твёрдого объекта по соседству: тела событий упрощённые, не форма спрайта.

## Переходы
Команда Перейти на локацию по умолчанию:0.25с затемнение → смена карты в чёрном
→0.25с проявление. Старые двери также получают этот эффект автоматически.
В форме команды Переход:Затемнение/Без эффекта. Чтобы изменить шаблонную дверь,
открыть её страницу и команду перехода. Движение/взаимодействие заблокированы
до завершения; последующие команды выполняются после проявления.
Эффект одинаково рисуется в preview и MP4. Во время перехода NPC также не шагают.
При Стоп посреди перехода видео закончится на текущем затемнённом кадре —
это записанное действие, не ошибка. Дайте двери завершить переход перед Стоп.
Поле transition_seconds (0–2) в JSON — длительность одной половины; UI длительности
пока нет. 0 или fade:false у команды дают прежний мгновенный переход.
